## R5.1 Every finding scored

Score = severity (S1 4, S2 3, S3 2, S4 1) × reach (every session 4, daily 3, occasional 2, rare 1) ÷ effort
(S 1, M 2, L 3), per plan §5. Order: S1 first (broken or inaccessible ships before polish whatever its score), then by
score, then by ID. MH = the `docs/must-haves.md` numbers the fix touches (— = none).

**Deterministic check.** The table was generated by a script that parsed every finding row in R2 and R3 (88 rows,
ID pattern `XX-n` with a severity cell) and recomputed each score from its severity, reach and effort cells. All 88
recomputed scores match the scores written in R2/R3. AX-15 and ML-6 are pass notes, not findings, and are left out;
IM-6 was not reproduced and is left out.
